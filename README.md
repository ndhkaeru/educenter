# Tiếng Trung Công Xưởng 365

Website giới thiệu khóa học tiếng Trung công xưởng với các trang:

- `Trang chủ`
- `Khóa học`
- `Blog`
- `Tài liệu`
- `Feedback`
- `Giới thiệu`
- `Liên hệ`

## Chạy local

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

Thư mục xuất bản nằm ở `theme/`.
